# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/jannikjordan/snapdate/security/advisories/new)
instead. Include the Snapdate version, Windows version and, if possible, a
sample file or steps that reproduce the problem.

You can expect a first answer within a few days. Fixes are released as a new
version with a note in the [changelog](CHANGELOG.md).

How Snapdate is protected, and how to verify a download, is described in
[docs/security.md](docs/security.md).
