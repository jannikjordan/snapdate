# 🛠️ Build & release

## Prerequisites

- Windows 10/11, [.NET SDK](https://dotnet.microsoft.com/download) as pinned in
  `global.json`, PowerShell 7.4+.
- For Native AOT locally: Visual Studio 2022+ or Build Tools with the
  *Desktop development with C++* workload. Without it, the build script falls
  back to a self-contained single-file exe.

## Everyday commands

```bash
pwsh scripts/build/build.ps1 -Target Test
```

```bash
dotnet run --project src/Snapdate.App
```

```bash
dotnet run --project tools/Snapdate.AssetGen -c Release
```

The last one regenerates `app.ico`, the logo PNGs and every screenshot in
`docs/images/` from the real UI. Run it whenever the UI changes.

See [scripts/build/README.md](../scripts/build/README.md) for every build target.

## Releasing a new version

1. Update `VersionPrefix` in `Directory.Build.props`.
2. Move the `Unreleased` entries in `CHANGELOG.md` into a new
   `## [x.y.z] - YYYY-MM-DD` section.
3. Commit (`chore(release): vX.Y.Z`) and push to `main`; wait for CI to pass.
4. Tag and push:

   ```bash
   git tag -a vX.Y.Z -m "Snapdate vX.Y.Z"
   ```

   ```bash
   git push origin vX.Y.Z
   ```

5. The **Release** workflow builds Native AOT executables for `win-x64` and
   `win-arm64`, zips, checksums, SBOM and provenance attestations, and creates a
   **draft** GitHub release.
6. Review the draft on GitHub and press **Publish release**.

## Release notes

Release notes are generated by `scripts/build/New-ReleaseNotes.ps1` from
[`.github/RELEASE_NOTES_TEMPLATE.md`](../.github/RELEASE_NOTES_TEMPLATE.md) and the
matching `CHANGELOG.md` section, so every release looks the same. To preview
them locally:

```bash
pwsh scripts/build/New-ReleaseNotes.ps1 -Version 0.1.0
```

## Release artefacts

| File | Purpose |
|---|---|
| `Snapdate-vX.Y.Z-win-x64.exe` | The app for most PCs (Intel/AMD). |
| `Snapdate-vX.Y.Z-win-arm64.exe` | The app for ARM PCs. |
| `Snapdate-vX.Y.Z-win-*.zip` | Exe plus README, CHANGELOG, LICENSE. |
| `SHA256SUMS.txt` | Checksums of all files. |
| `sbom.cdx.json` | CycloneDX software bill of materials. |
